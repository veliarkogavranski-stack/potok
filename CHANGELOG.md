# Changelog

## 1.0.30

- Renamed to Stream Reader (app title, Android label, Windows window title)

## 1.0.29
- Localization: English, German, Polish added; the app follows the system language (Russian is the fallback).
- Materials for publishing on GitHub: README, LICENSE, CHANGELOG, CI workflow.

## 1.0.28
- Windows: fixed repeated "Open file" clicks spawning multiple dialogs.

## 1.0.27
- Windows build shipped as a portable zip archive.

## 1.0.24 - 1.0.26
- "Resume" moved to a bottom-row button with a full history sheet; items can be removed without closing the sheet.

## 1.0.23
- Home screen reworked: invite button when empty, plain "Read" when text is present.

## 1.0.25 (hotfix)
- Fixed book titles shown as "?????????" for cp1251 FB2 files.

## 1.0.21 - 1.0.22
- "My books" shelf: opened books are copied to Documents/My books, duplicates skipped.

## 1.0.19 - 1.0.20
- Restored the native Android bridge (book list, storage access) that was missing from builds; more book extensions scanned.

## 1.0.18
- File formats extended: RTF, ODT, DOC, MOBI/AZW/AZW3/PRC; PDF on Android via a bundled parser.

## 1.0.10 - 1.0.17
- Outline view (table of contents) with tap-to-jump; tablet layout; broken FB2 handling; compact bottom bar.

## 1.0.8 - 1.0.9
- Seek hint plate; live progress slider with elapsed/remaining time.

## 1.0.5 - 1.0.7
- Pinch to change font size on the word zone; hit-test fix so the whole zone is touchable.

## 1.0.4
- New dark graphite color scheme.
