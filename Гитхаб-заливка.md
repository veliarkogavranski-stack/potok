Шаги (один раз, в любом терминале с git):

1. Создай пустой репозиторий на github.com (без README и .gitignore - они уже есть).
2. В папке проекта:
   git init -b main
   git add .
   git commit -m "Flow: RSVP speed-reading, v1.0.29"
   git remote add origin https://github.com/<твой-логин>/<имя-репозитория>.git
   git push -u origin main

Если git попросит вход - это окно GitHub в браузере, логинишься там.

3. Релизы: после пуша вкладка Actions соберёт артефакты. Для официального релиза:
   git tag v1.0.29 && git push origin v1.0.29
