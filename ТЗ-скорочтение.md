# ТЗ: приложение для скорочтения «Поток» (RSVP-читалка)

Обновлено: 2026-10-31. Слово Отца: «делай». Решения Отца: Flutter; сначала Windows MVP, Android следом на том же коде. Веб-вариант снят.

## 1. Суть
Загруженный текст (книга, статья, документ) выводится на экран по одному слову в фиксированной точке - как Spreeder (spreeder.ru). Глаза не двигаются, скорость задаёт пользователь.

## 2. Ключевая механика
- Пайплайн: файл/буфер -> извлечение текста -> разбивка на слова -> очередь -> показ по таймеру.
- ORP (оптимальная точка распознавания): фокусная буква (~40% длины слова) стоит на одной вертикальной оси по центру, выделяется цветом. Обязательно.
- Пауза после пунктуации: точка/восклицание/вопрос x2.5, запятая/двоеточие x1.5, конец абзаца x3.
- Слова длиннее 13 знаков: удвоенная задержка или разбивка на части.
- Числа и сокращения: увеличенная задержка.

## 3. Управление
- Скорость 100-1500 WPM, шаг 25, регулировка на лету (колесо, стрелки).
- Пауза/продолжить: пробел, клик.
- Назад/вперёд по предложениям и абзацам; «перечитать последнее предложение» - одна клавиша.
- Прогресс: полоса + «слово N из M», оценка времени до конца.

## 4. Ввод текста (приоритет)
1. Вставка из буфера, ручной ввод (MVP).
2. .txt, .md (UTF-8, автоопределение кодировки).
3. .pdf, .epub, .docx - следующим шагом.
4. URL статьи - позже.

## 5. Экран
- Режим чтения без отвлекающего; шрифт 32-64 pt настраиваемый.
- Тёмная/светлая тема.
- Фокус-зона с направляющими линиями вокруг точки показа.
- Статистика сессии: слов, средняя скорость, время.

## 6. Настройки (сохраняются локально)
WPM, шрифт, размер, тема, длина пауз, режим «1 слово / чанки по 2-3».

## 7. Не входит в первую версию
Библиотека книг, облако, синхронизация, аккаунты. Модель данных (Документ -> Сессия -> Прогресс) заложить в архитектуру.

## 8. Стек и план (решено 31.10.2026)
- Flutter (Win + Android одной кодовой базой), состояние - встроенными средствами без тяжёлых зависимостей.
- Этап 1 (MVP, Windows): вставка текста + txt/md, ORP-вывод по таймеру, скорость, пауза, прогресс, настройки, тёмная тема. Приёмка: прогон приложения, чтение русского текста 500+ слов без пропусков и дублирования.
- Этап 2: Android-сборка того же кода, адаптация жестов.
- Этап 3: pdf/epub/docx, статистика, чанки.

## 10. Что пришлось починить для сборки (31.10)
- **Кириллица в пути ломает MSBuild**: `CUSTOMBUILD : error : Unable to read file: E:\Галатея\...\.dart_tool\flutter_build\...\app.dill`, кодировка пути искажается. Решение: собирать из ASCII-пути (копия в `C:\potok-build`), исходники держать в доме.
- **lib/main.dart был под старые API**: `FilePicker.pickFiles()` → `FilePicker.platform.pickFiles()` (file_picker 7.x); `desktop_drop` зафиксирован на `0.8.0`, потому что в коде `DropTarget(onDragDone: ...)` с `details.files`, а в 0.9.2 API другой (`onDrop`, `details.items`).
- В `pubspec.yaml` добавлены недостающие зависимости: `archive ^4.5.2`, `desktop_drop 0.8.0`, `file_picker ^7.0.2`, `xml ^7.1.0`.
- Android-сборка (этап 2) невозможна: `flutter doctor` — `Unable to locate Android SDK`. Нужна установка Android Studio/SDK, тогда APK соберётся из того же кода.

## 12. Библиотека на телефоне (31.10.2026)

Причина: Android не знает MIME для .fb2, поэтому системный выбор файлов (SAF) его не показывает; FileType.any (*/*) проблему не лечит — фильтрация идёт на стороне файлового провайдера.

Решение: собственный список книг.
- ndroid/app/src/main/kotlin/com/example/potok/MainActivity.kt — MethodChannel("potok/storage"): hasAccess, equestAccess (настройки «Доступ ко всем файлам»), listFiles (Загрузки, Документы, /storage/emulated/0/Books, /storage/emulated/0/Поток), dataDir.
- AndroidManifest.xml — MANAGE_EXTERNAL_STORAGE + READ_EXTERNAL_STORAGE (maxSdk 32).
- lib/main.dart — экран LibraryScreen (кнопка «Мои книги», только Android), фильтр расширений fb2/txt/epub/docx/pdf/zip/doc, размер и папка у каждого файла, экран выдачи доступа.
- Побочно исправлено: история чтения на Android писалась в путь из APPDATA (его нет) — теперь берётся ilesDir приложения.

Ограничение: MANAGE_EXTERNAL_STORAGE — специальное разрешение, для Google Play требует обоснования; для личной установки по APK работает.
